# 我的衣橱 · 独立版

一个装在手机上的衣橱小程序：给衣服拍照、自动抠图换白底，随时搭配。**不需要 Claude 账号，可以离线使用，所有照片和记录只保存在你自己的手机上。**

## 功能

- 衣橱：分类、颜色筛选、搜索、按穿着次数排序、多选删除
- 自动抠图：去掉背景换成纯白，统一亮度和色调；也能把衣服从模特身上抠出来
- 正面、背面、细节多张照片；画笔去除 logo 和水印
- 搭配：锁定、随机换、配色检查、"今日提醒"、按天气和场合自动推荐
- 穿着记录、已存搭配、套装分类
- 备份导出和导入（换手机时用）
- 中文 / English 切换

和 Claude 版相比，独立版没有"自动识别类型和颜色"和"Claude 推荐搭配"：类别和颜色要自己点选，推荐搭配改为按配色规则和少穿优先自动挑选。

## 一、放到网上（只需做一次）

App 需要放在一个网址上，手机才能安装。用免费的 GitHub Pages 就可以，在电脑上操作，大约 10 分钟。

1. 打开 https://github.com 注册或登录。
2. 点右上角 **＋ → New repository**。名字随便起，比如 `my-closet`；选 **Public**（免费账号的 Pages 需要公开仓库）；点 **Create repository**。
3. 在新仓库页面点 **uploading an existing file**。解压 zip，把 `closet-app` 文件夹**里面的所有文件和文件夹**一起拖进去（不要拖外层文件夹本身），等上传完点 **Commit changes**。
   - 所有文件都小于 25 MB，可以直接在网页上传。
   - 上传后确认能看到 `index.html`、`model`、`ort`、`fonts`、`icons` 这几项。
4. 进入仓库的 **Settings → Pages**。在 *Build and deployment* 里，Source 选 **Deploy from a branch**，Branch 选 **main** 和 **/(root)**，点 **Save**。
5. 等 1–2 分钟后刷新这个页面，顶部会出现网址，类似 `https://你的用户名.github.io/my-closet/`。

> 仓库是公开的，但公开的只是 App 本身。每个人的衣服照片和记录都只存在自己的手机里，不会上传到任何地方。

## 二、在手机上安装（你和朋友都一样）

把上面的网址发给朋友，用手机打开：

- **iPhone**：用 **Safari** 打开 → 点底部的 **分享** 按钮 → **添加到主屏幕**。
- **Android**：用 **Chrome** 打开 → 点右上角 **⋮** → **安装应用** 或 **添加到主屏幕**。

之后从主屏幕的图标打开，就像普通 App 一样。

**第一次添加照片时**，App 会下载抠图工具（约 45 MB；第一次处理模特照片时会再下载约 45 MB），建议连着 Wi-Fi。下载一次后就保存在手机上，之后断网也能用。

## 三、重要提醒

- **请从主屏幕图标打开。** 尤其是 iPhone：只在 Safari 里打开、没有添加到主屏幕的网页，如果长时间不用，系统可能会清掉它的数据。
- **定期备份。** 点右上角「备份 → 导出备份」，把文件存到网盘或发给自己。换手机或误删时，用「从备份导入」就能恢复。
- **不要在无痕模式下使用**，否则关闭后数据就没了。
- 每个人的衣橱互相独立。同一个人的手机和电脑之间不会自动同步，可以用备份文件转移。

## 四、以后更新 App

用新版本的文件覆盖仓库里的旧文件即可。大家下次打开 App 时会自动更新，衣橱数据不受影响。

## 五、在自己电脑上试用（可选）

在 `closet-app` 文件夹里打开终端，运行 `python3 -m http.server 8000`，然后在浏览器打开 http://localhost:8000 。直接双击 `index.html` 是打不开抠图功能的。
